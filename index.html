About this GUI:

This GUI runs on the python module pyscript, which is used of compiling python code on a website. In order to run correctly, this GUI needs to be hosted on a web server and needs access to the internet. This is a limitation caused by the browser, not pyscript, and cannot be avoided. A simple web server can be hosted by running the command py -m http.server, going to localhost:8000 and navigating to the folder this gui is located in. This will allow the GUI to access the script files neccessary for it to work. The GUI also requires an internet connection to access core scripts related to the python compiler built into pyscript and to download the datasets used by the GUI, because they cannot be stored locally. The GUI may take a few seconds to finish loading even after loading screen has disappeared.
